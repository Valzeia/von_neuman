# von_neuman
Experiment of an RTS game.

## Development container

C# work, Git, and PostgreSQL run in a Dev Container. The Unity Editor stays on the host. See [.devcontainer/README.md](.devcontainer/README.md).

Reopen the folder with **Dev Containers: Reopen in Container**. Postgres is then available at `localhost:5432` (`von_neuman` / `postgres` / `postgres`).
